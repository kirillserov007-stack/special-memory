# Blocks Stafn — APK build

Файлы:
- main.py — игра
- buildozer.spec — настройки Buildozer
- .github/workflows/build.yml — автоматическая сборка APK на GitHub Actions

## На телефоне
1. Создай новый GitHub-репозиторий.
2. Распакуй ZIP и загрузи ВСЕ файлы и папки в корень репозитория.
3. Открой вкладку Actions.
4. Запусти `Build Blocks Stafn APK` через `Run workflow`.
5. После успешной сборки открой результат запуска и скачай artifact `Blocks-Stafn-APK`.
6. Внутри artifact будет APK.

Игра рассчитана на Kivy и сборку Android arm64.
